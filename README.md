# FocusUp

FocusUp is a local-first Chrome extension for intentional browsing.

Version 0.1 provides Focus and Personal modes, persistent local settings, and a foundation for future content rules. No blocking is active yet.

## Install

1. Open `chrome://extensions` and enable Developer mode.
2. Select **Load unpacked** and choose this repository's root folder.
3. Open the FocusUp popup, select a mode, and reopen it to verify persistence.
