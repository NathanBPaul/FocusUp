# FocusUp agent instructions

FocusUp is independent of ShortBlock. Never edit ShortBlock.
Build a local-first Manifest V3 Chrome extension with vanilla JavaScript, HTML and CSS.
Keep profile configuration, rules evaluation, storage and UI separate.
Start with Focus and Personal modes; future plans include website blocking, granular content permissions, presets, commitments and private analytics.
Avoid unnecessary permissions, external services and dependencies.
Test each feature before adding the next.
Always ask for approval of the exact commit message before committing or pushing.
Do not claim a regular extension can prevent its own removal.
Use simple, friendly, professional wording throughout the product. Explain controls in everyday language, name Focus Mode and Personal Mode consistently, and give clear next steps in feedback. Avoid developer terms in user-facing text and describe limitations accurately.
